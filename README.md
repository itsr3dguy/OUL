# Open Use License (OUL)

A simple, permissive source-available license designed to allow wide usage while
protecting creator attribution.

## What is OUL?

The Open Use License (OUL) allows developers to freely use, modify, and include
software in personal, educational, and commercial projects while ensuring the
original creator receives proper credit.

OUL is designed for creators who want their work to be accessible without
allowing others to simply resell their code as their own product.

## Allowed

Under the Open Use License, you may:

- ✅ Use the software personally.
- ✅ Use the software commercially.
- ✅ Modify the software.
- ✅ Create derivative versions.
- ✅ Include the software in larger applications, games, websites, or services.
- ✅ Publish modified versions with proper attribution.

## Not Allowed

You may not:

- ❌ Sell the software itself.
- ❌ Sell the source code as a standalone product.
- ❌ Remove copyright notices.
- ❌ Claim ownership of someone else's work.
- ❌ Distribute modified versions without stating that they are modified.

## Requirements

If you use software licensed under OUL, you must:

1. Keep the original license included.
2. Provide credit to the original creator.
3. Link back to the original repository.
4. Clearly state when modifications have been made.

## Why OUL?

Many licenses either:

- Allow everything, including people selling your work unchanged.
- Restrict commercial use too heavily.
- Become complicated legal documents nobody reads.

OUL attempts to provide a middle ground:

**Use it. Build with it. Improve it. Give credit. Don't sell the code itself.**
